# AI-Assistant-using-Raspberry-Pi

### Overview
This project successfully builds a **fully functional, voice-controlled AI Assistant** on a **Raspberry Pi** using open-source tools. The assistant can understand voice commands, process them intelligently, and respond via speech. It supports offline operation for privacy and works without constant internet connectivity, making it ideal for learning, home automation, and personal use.

### Key Highlights
- **Offline Speech Recognition** using Vosk
- **Natural Language Processing** with GPT-Neo for smart responses
- **Text-to-Speech** using pyttsx3
- **Custom Wake Word** support (e.g., “Hey Pi”)
- **Features**: Tell time/date, web search, weather updates, set reminders, answer questions, and more
- **Hardware**: Raspberry Pi + USB Microphone + Speaker
- **Completely customizable** and open-source

### Objectives
- Develop a voice-controlled AI assistant on Raspberry Pi
- Implement robust offline/online speech recognition and TTS
- Enable useful daily tasks and smart interactions
- Create an educational, low-cost, privacy-focused alternative to commercial assistants

### Results
- Successfully recognizes and responds to voice commands with good accuracy (85–90% in quiet conditions)
- Low latency responses (under 2 seconds for simple tasks)
- Works reliably offline using Vosk + pyttsx3
- Modular Python code allows easy extension
- Demonstrated real-time voice interaction on Raspberry Pi hardware

### Technologies & Components
- **Hardware**: Raspberry Pi (3B+/4/5), USB Microphone, Speaker
- **Software**: Raspberry Pi OS, Python
- **Key Libraries**: `speech_recognition`, `vosk`, `pyttsx3`, `GPT-Neo`, `webbrowser`, `datetime`
- **APIs** (optional): OpenWeatherMap, Google Search
